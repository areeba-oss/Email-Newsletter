Meta Updates Ad Attribution to Improve Measurement Clarity

Meta announced changes to ad measurement, redefining click-through attribution to count only link clicks for website and in-store conversions. Other actions like shares and saves will move to “engage-through attribution,” helping ecommerce brands and marketplace sellers better align reporting with tools like Google Analytics. The update aims to reduce reporting gaps and give advertisers more confidence in performance data. Read more

Anthropic Expands Claude Memory & Makes Switching Easier

Anthropic announced that memory features for Claude are now available on the free plan, along with a new tool that lets users import data from chatbots like ChatGPT and Gemini. This update makes it easier for users to switch platforms without losing past context. For e-commerce teams using AI for workflows and automation, this lowers the barrier to testing alternative AI tools. Read more

Google Sets $5 Minimum Budget for Demand Gen Campaigns

Google announced that starting April 1, 2026, the Google Ads API will require a minimum daily budget of $5 for all Demand Gen campaigns. This helps campaigns exit the “learning phase” faster, but ecommerce brands and Amazon-focused advertisers running low-budget tests will need to adjust spend to stay compliant. Existing campaigns under $5 can continue running, but any edits will trigger the new rule Read more

Reddit Tests AI-Powered Shoppable Product Carousels

Reddit is testing an AI-powered shopping feature that turns real user product recommendations into shoppable carousels with prices and buy links in the U.S. The AI connects organic thread mentions to retail inventory, blending community trust with direct e-commerce. For brands and marketplace sellers, this could turn Reddit discussions into instant sales opportunities. Read more
